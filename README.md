# UserSwitch

Minimal launcher shortcut for the native Android / GrapheneOS user switcher.

## How it works

UserSwitch hosts the existing system Multiuser widget and activates its user-switch action.
The actual user switch remains handled by the privileged Android system component.

UserSwitch requires:

- no root
- no Shizuku
- no ADB
- no accessibility service
- no network access
- no privileged app permissions

## Platform

Designed and tested for GrapheneOS.
